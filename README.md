# dsh-update-guard · 更新闸

插件自动更新的护栏（Host 插件，零依赖、无构建）。

## 它解决什么问题

自动更新对**改过源码的插件**是毁灭键：补丁一上，本地改动全没。本插件把评论区经验固化成三条铁律：

1. **回滚位**——更新前必须有备份（git commit 或 zip 快照），否则禁更。
2. **指纹**——装后必须回读版本号对账，"装了"≠"装成了"。
3. **只查不装**——拿不准就先查远端最新版，把决定权留给人。

## 工具

**update_guard**：传 gitManaged / dirty / backuped 三态，本地判定 `放行 / 先存档 / 放行（有备份）/ 拒更` 并给出理由。

## 安装

cordis.patch.yml 已含 bundle patch，`enabled: true` 即挂载。
